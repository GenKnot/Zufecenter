# 浙江财经大学语言中心课程教学大纲

本文件为语言中心课程教学大纲，用于课程介绍、教学组织和学习咨询。各期课程在保持培养目标和核心内容一致的前提下，可根据学员基础、教学进度和当期排课进行适当调整。

本文件夹将现有 26 门课程展开为详细课程方案：

- [英语课程](./english.md)：8 门
- [法语课程](./french.md)：6 门
- [日语课程](./japanese.md)：6 门
- [韩语课程](./korean.md)：6 门

每门课程包括：课程定位、入班基础、定制教材、章节周期、知识与能力内容、课堂任务、课后作业、章节检测、期中或模拟考试、结课考试与成果。

## 共通原则

- 多数综合课程原则上约每两个月开放一次报名或衔接安排，具体开课以人数和排课为准。
- 教材为语言中心按级别与教学目标编写的定制教材、练习册和数字资源。
- 零基础课程无前置要求；其余课程须完成前一级别或通过相应分级测评。
- 费用不在网站公开，统一表述为“请联系语言中心咨询当期课程安排与费用”。
- 评价采用过程性任务与阶段考核结合，不以一次笔试作为唯一依据。
- 课程采用“课程负责人＋协同教师”的教学组织方式。课程负责人统筹教学目标、材料与评价，协同教师可承担部分单元、口语训练、作业反馈或阶段测评；当期安排如有调整，由同语种教学组协调接续。
