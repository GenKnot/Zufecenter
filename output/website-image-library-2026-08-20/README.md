## 生成风格

使用内置 ImageGen 生成。统一采用自然纪实校园摄影方向：降低人物占比，使用空镜、远景或背影；保留普通桌椅、墙面磨损、阴天和荧光灯混合光、轻微杂乱与传感器颗粒；避免耳机、麦克风、正面摆拍、整齐人群、电影调色、样板间和可读文字。

这些图片适合作为通用课程氛围、过场或装饰素材，不应标注为某一栋真实校舍、某一场真实活动或某一位真实学员的纪实照片。
